# Spam Detection using Machine Learning

## 📌 Problem

Classify messages as Spam or Not Spam.

## ⚙️ Approach

* Text preprocessing using CountVectorizer and TF-IDF
* Applied Naive Bayes and Logistic Regression
* Compared model performance

## 📊 Results

Naive Bayes performed better for text classification.

## 🛠️ Tech Stack

* Python
* scikit-learn
* Pandas

## 🚀 How to Run

1. Install dependencies
2. Run model.ipynb
